# _exports — AI-Readable Edit Export Files

This folder is auto-generated by the Site Builder Server.

## Usage

When you request `GET http://localhost:3031/api/export/CORE-01`, the server:
1. Generates a structured `.md` export file
2. Saves it here as `EXP-YYYYMMDD-{pageId}.md`
3. Returns the content as a plain text download

## How to use with Cursor

**Option A — Copy/Paste:**
Open the export URL in your browser → select all → paste into Cursor chat

**Option B — File Attach:**
Attach the `.md` file from this folder directly to your Cursor chat

**Option C — API:**
The server returns the export as a `text/plain` response with
`Content-Disposition: attachment` — your browser will download it automatically.

## Export Format

Each file contains:
- `EXPORT_ID` — unique ID for tracking
- `PAGE_ID`, `RENDER_TYPE`, `SRC_FILE`, `FULL_PATH`
- `PENDING EDITS FROM INBOX` — all unresolved inbox entries for this page
- `RENDER INSTRUCTIONS FOR CURSOR` — differs for STATIC vs REACT vs REACT-PLANNED
- `SECTION MAP` — maps section IDs to human labels
- `HOW TO USE THIS EXPORT IN CURSOR` — step-by-step instructions

## Render Type Guide (for Cursor)

| RENDER_TYPE     | What Cursor should do                          |
|-----------------|------------------------------------------------|
| `STATIC`        | Edit the HTML file directly                    |
| `REACT`         | Edit the `.tsx` component → run `next build`   |
| `REACT-PLANNED` | Edit HTML for now — avoid deep structural hacks|
